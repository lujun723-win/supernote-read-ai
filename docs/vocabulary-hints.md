# 页内生词提示

## 用户需求

- 在英文 PDF/EPUB 页面上显示类似 Kindle 的简短中文生词提示。
- 用户可选择提示起点：小学、初中、高中、四级、六级、考研、雅思/托福。
- 只显示达到所选级别及更难的词。
- 离线完成识别、分级和释义，不调用 AI。

## 交互

1. 在设置页选择“生词提示起点”。
2. 单击词典悬浮按钮，在顶部的“选择文本 / 圈选 OCR / 生词提示”三种模式中选择“生词”。
3. ReadAssist 隐藏自身窗口，截取当前页并离线识别。
4. 页内最多显示 20 个最难词，释义层不拦截翻页、选词和书写。
5. 模式选择会保存，悬浮按钮分别显示“取 / 圈 / 译”；双击直接执行当前模式。
6. 右下角“隐藏 / 显示”按钮只切换标注可见性；词典页的“清除”会彻底移除标注和开关。
7. 应用不监听翻页；翻页后需再次双击“译”扫描新页面。
8. 建议将阅读器行间距设为最宽，为释义留出更完整的行间空间。

## 分级规则

- 优先使用 ECDICT 中考、高考、CET-4、CET-6、考研、雅思/托福标签。
- 无标签词使用 ECDICT 词频位次分档。
- 复数、过去式、分词等词形继承原型的级别。
- Lexile 是文本整体难度，不用作单词分级。

## 技术方案

- ML Kit Latin OCR 返回单词文本和 `boundingBox`。
- `vocabulary_hints.dat` 以 gzip 格式保存单词、级别、词频和短释义，由现有 ECDICT StarDict 资产生成；中性扩展名避免 Android 构建时自动展开并改名。
- 选词器去重、过滤门槛、按难度排序并限制 20 个。
- 全屏 `TYPE_APPLICATION_OVERLAY` 只负责绘制，设置 `FLAG_NOT_TOUCHABLE`，不改变 Supernote 原有触摸行为。
